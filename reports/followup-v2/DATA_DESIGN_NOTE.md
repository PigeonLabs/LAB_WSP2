# Followup-v2 데이터 동결 및 한계

기존 `pilot-v1`을 그대로 보존하고 새로운 생성 규칙·문장·내용·평가 분할을 만들었다. 모델 결과를 이용해 문항을 고르거나 수정하지 않았다. 데이터는 `data/followup-v2/`의 여섯 JSONL과 manifest로 동결되어 있으며, 파일 바이트 해시와 레코드 해시를 함께 확인한다. 다른 내용으로 덮어쓰기를 요청하면 실패한다.

| 분할 | 문항 수 | 역할 |
|---|---:|---|
| train | 16,384 | 독립 초기화 학습, 학습 데이터에서만 선택하는 few-shot 예시 |
| calibration | 768 | 과제 능력·프롬프트 형식 선택 |
| D1 | 768 | 뉴런 후보 선택 |
| D2 | 768 | 정렬·가중치·참조 분포·인과효과 정규화 |
| D3 | 768 | 독립 관찰 평가 |
| D4 | 768 | 독립 인과 평가 |

총 20,224개 문항이다. 평가 분할마다 **4과제 × 24wrapper × 8문항**이며 과제·wrapper마다 참4개, 거짓4개다. 각 대응 donor pair는 같은 과제·wrapper·내용·생성 seed에서 나온 반대 정답 문항 두 개로 구성된다. 생성 seed는 `2718, 3141, 5772`이며 각 평가 분할에 seed별256문항, 각 과제·wrapper에 세 seed가 모두 포함된다. 생성 seed는 모델 초기화 seed와 별개다.

원본 프롬프트의 최대 길이는122 UTF-8 bytes, 학습 프롬프트 최대118 bytes다. few-shot 변환 이후 길이는 별도 점검 대상이며 이 숫자에 포함되지 않는다. `span`은 원본 프롬프트에서 과제 statement의 문자 범위다.

## 수정한 우회 경로

- **산술:** 거짓 합계는 실제 합과 같은 parity, 같은 십진수 자릿수를 유지한다. 오답은 ±1로 제한하지 않는다. 동결 데이터의 오답 차이는 −146부터150까지139종이다. 따라서 짝홀성이나 출력 자릿수만으로 정답을 구분할 수 없다. 피연산자 범위는0–127이며 덧셈만 다룬다.
- **수 비교:** 같은 자릿수의 서로 다른 수를 사용하고 donor는 두 피연산자의 순서를 반전한다. 관계 단어는 pair 안에서 동일하므로 단어 자체나 자릿수 비교만으로 참·거짓을 나눌 수 없다.
- **부정/논리:** 인접 숫자 suffix를 가진 속성명을 없앴다. P,Q 등의 세 변수에 T/F를 명시하고 AND/OR/XOR/NOT 식의 값을 판단한다. pair는 동일한 식을 사용하며 T인 변수의 총수도 같다. 속성명 동일성이나 T 개수만으로는 판단할 수 없다. NOT은 모든 식에 포함된다.
- **괄호:** 거짓 문항은 올바른 괄호열에서 종류가 다른 두 닫는 기호의 위치를 교환한다. 참·거짓 pair는 **문자 multiset, 길이, 여는/닫는 기호의 전체 위치 패턴**이 동일하다. 단순 개수, 첫·끝 기호 방향, 종류를 무시한 깊이 변화만으로는 해결할 수 없다.

## 분리와 검증

여섯 분할에서 완전한 wrapper 문장, 정확한 prompt, controlled content key, 숫자 피연산자 unordered tuple을 중복시키지 않았다. 숫자 tuple은 산술과 수 비교를 가로질러서도 분할 간 분리된다. 내부 의미 문법과 숫자 범위는 공유한다.

검증기는 의미 메타데이터의 oracle, statement와 메타데이터의 일치, 정답 continuation, span, 분할 중복, donor 쌍, wrapper별 참·거짓 균형을 확인한다. 테스트에서는 **전체20,224개 문항의 실제 statement를 다시 파싱**하고 별도 산술·비교 계산, Boolean 재귀 파서, 괄호쌍 반복 제거를 통해 정답을 재검증했다. 기존 데이터 파일 불일치 덮어쓰기 거부와 파일 변조 감지도 테스트한다.

실행: `python3 -m unittest tests/test_followup_data.py -v`

로드: `from src.followup_data import load_dataset; dataset = load_dataset()`

manifest SHA256: `bbe384e2c2851f4ce9521b37d1a701a684d2cc4b1eccf8e02c31855ae62aabdc`

## 여전히 필요한 해석 제한

24wrapper는 ID나 숫자 접두어로만 구분한 템플릿이 아니라 서로 다른 자연어 지시문이다. 그러나 같은 의미 문법을 감싸는 수작업 paraphrase이므로24개의 독립적인 semantic grammar나 자연어 모집단 표본으로 취급할 수 없다. **추론 범위는 이 합성 과제와 wrapper 집합에 조건부**다. 통계 재표집은 wrapper를 네 과제 전체에 걸쳐 함께 묶어 수행해야 한다.

산술은 parity·자릿수보다 복잡한 숫자 분포 단서가 남을 수 있다. Boolean 문법은 유한하고 일부 할당에서는 특정 변수가 결과에 영향을 주지 않을 수 있다. 괄호 오류는 국소적인 종류 불일치로 발견될 수 있으므로 성능이 좋아도 재귀적 parsing 학습을 입증하지 않는다. 세 생성 seed는 문항 표본 변동을 탐색하게 하지만 독립 모델 seed나 실제 자연어 사례를 대체하지 않는다.

D3/D4를 본 이후 이러한 한계를 해결하려고 동결 데이터를 교체하지 않는다. 추가 개선은 새로운 버전과 새로운 최종 테스트셋으로 수행해야 한다.
