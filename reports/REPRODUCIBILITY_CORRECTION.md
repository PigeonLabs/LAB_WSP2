# 재현성 수정 기록: 레이블 셔플 대조군의 Python 해시 순서 의존성

기록일: 2026-11-04 KST. E1/E2/E3 본 실행 후 최종 감사에서 발견한 구현 오류다. 기존 실험 파일을 수정하거나 결과가 유리해지도록 재실행하지 않았다.

## 오류와 원인

`src/alignment.py::similarity_for_method(..., method='label_shuffled')`는 개념별로 진실 레이블을 섞는다. 원래 코드는 `for name in set(names)`로 개념을 순회했다. 문자열의 집합 순서는 Python 프로세스의 해시 시드에 따라 달라지므로, NumPy 난수 시드를 동일하게 지정해도 개념에 배정되는 난수열 구간이 달라졌다. 그 결과 프로세스 간 레이블 셔플 대조군의 실현값과 해당 매칭이 달라질 수 있었다.

수정은 `for name in sorted(set(names))`로 순서를 고정하는 것뿐이다. 정렬 기준, 하이퍼파라미터, 평가셋, 모델 가중치, 후보 뉴런, 주 평가 지표는 변경하지 않았다. 수정 후 새로운 실행의 레이블 셔플은 동일 입력·시드·라이브러리 환경에서 Python 해시 시드와 무관하게 생성된다.

같은 독립 시드 모델 쌍을 다룬 E1과 E3의 보존된 지표를 비교했다.

원본: [E1 지표](../results/pilot-v1/E1/trained/metrics.json), [E3 지표](../results/pilot-v1/E3/seed11_seed29/metrics.json).

두 저장 매핑의 공통 방법을 직접 비교했을 때 다른 방법은 `label_shuffled`뿐이었다. E1에만 `weight` 방법이 추가되어 있으나, 위 BH 보정에 들어간 비교 집합은 두 실행 모두 같은 다섯 비교였다.

의미 정렬 대 활성값 정렬의 원래 효과와 p는 동일하지만, BH 보정은 같은 검정 집합의 다른 p에도 의존한다. 따라서 셔플 대조군 비교의 p 변화가 해당 집합의 q에도 영향을 주었다. 특히 q=0.05 기준의 경계를 넘는 변화이므로 숨기거나 동일한 재현 결과라고 표현해서는 안 된다. E1과 E3은 독립적인 재현 실험으로 간주하지 않는다. 두 결과의 차이는 보존된 대조군 실현값의 출처와 함께 해석해야 한다.

직접적인 오류 범위는 레이블 셔플 대조군 생성이다. 그 대조군을 포함하는 비교의 통계와 다중 비교 보정은 간접적으로 영향을 받을 수 있다. 원본 모델 학습, 수집된 활성값, 입력 데이터, 레이블 셔플을 사용하지 않는 정렬의 원래 측정값을 이 수정으로 변경하지 않았다. 다른 모델 쌍의 과거 대조군을 새 코드로 재생성하여 기존 실현값과 동일하다고 가정해서도 안 된다.

## 보존과 재생 원칙

- 기존 `results/pilot-v1/`의 측정 파일 및 `frozen_mappings.json`은 보존한다.
- 과거 보고 수치의 정확한 재생에는 당시 저장한 `frozen_mappings.json`을 사용한다. 수정된 함수로 새 대조군 매칭을 만들어 원래 결과를 대체하지 않는다.
- 새 실험은 수정된 구현을 사용하고 별도 실험 버전과 코드 출처를 기록한다. 과거 실현값과 비교할 때는 대조군 재생성 여부를 표시한다.
- 발견 시점은 최종 감사 단계다. 테스트 결과를 보고 매칭 방법이나 하이퍼파라미터를 튜닝한 변경이 아니다. 기존 가설 판정을 유리한 q로 바꾸기 위한 재실행도 수행하지 않았다.
- 본 수정 작업에서는 실험을 재실행하지 않았으며, 기존 결과물을 덮어쓰지 않았다.
